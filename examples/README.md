# Examples

## `car-wash-demo.html`

A complete playable ad produced by the v2 pipeline from a car-wash brief.

- Single self-contained HTML file (~1.6 MB) with all images inlined as base64
- MRAID 3.0 wrapper, touch + mouse input, `requestAnimationFrame` game loop
- Opens directly in a browser: `open examples/car-wash-demo.html`

Generated output is otherwise written to `output/`, which is git-ignored.
